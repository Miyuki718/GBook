# GBook 本地 v1 范围

目标：围绕原文保存个人想法，并和 GPT 持续讨论。优先 Windows 本地单用户可运行、数据可靠和清楚的失败状态。

已落地：书架管理、TXT/Markdown/无 DRM EPUB 导入、章节阅读、选区和高亮、批注、全部笔记搜索、正文搜索、进度、书签、OAuth、流式共读和多轮历史、备份恢复、独立 STDIO MCP。

书籍默认保留在本机；只有用户主动发起共读才发送所选片段及必要上下文。没有后台上传整本书或假冒模型回复。

不包含：公网多用户、云端同步、移动原生应用、DRM、PDF/OCR、EPUB CSS/插图排版保真。后续按需求扩展，不将这些功能误记为本地 v1 已完成。
